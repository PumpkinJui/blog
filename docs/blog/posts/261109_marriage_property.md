# 古代的婚姻形式及财产分配制度

《中华农耕文明》的小组汇报。因为自己写得很满意，上台表现效果自认也很好，所以在这放一份。

---

<!-- more -->

今天我们讲的题目是《古代的婚姻形式及财产分配制度》。

首先来看古代的婚姻形式。要讲婚姻形式，我们首先要知道婚姻是怎么来的。《礼记·昏义》中记载：「昏礼者，将合二姓之好，上以事宗庙，而下以继后世也。故君子重之。」就是说，婚礼是为了结合两个姓氏之间的友好关系，上用来祭祀宗庙，下用来延续后代，所以君子非常重视它。从这句话中我们可以看到，婚姻的主要原因并不是因为男女之间的爱恋，而更多是为了社会和家庭的责任。这其中就包括了家族间的联结，比如通婚，还有祭祀先祖。而其中最为重要的当属延续香火。到了今天，我们已经很少提到通婚了，也很少再有祖祠这样的地方祭拜了，但延续香火、传宗接代仍然是人们结婚的影响因素之一，可见其重要性。

那么，为什么人们把延续香火看得如此重要呢？「延续香火」，字面意思就是把「香火」延续下去。而「香火」，原本指的就是祭祀先祖的香火。我国古代的祖宗崇拜很普遍，人们相信逝去的先人仍旧以某种方式存在，能影响到后代的祸福，因而形成了对祖宗的敬畏，进一步就出现了对祖宗的祭祀与供奉。但如果没有子嗣，祖宗祭祀就会结束，香火就会断绝。要想延续宗嗣，就必须生育，而且是生育儿子。

人们重视传宗接代，也有儒家思想的引导。在儒家思想中，「仁」是整个思想体系的核心，而「孝」是「仁」的根本。《孟子·离娄上》中记载：「不孝有三，无后为大。」按照儒家对「孝」的理解，「孝」首先就意味着生育子嗣。

除了这些因素以外，古代的老百姓聚族而居，经营单一种植业，需要强劳动力。没有后代不仅要承受精神上的「绝后」「断子绝孙」的痛苦，而且要承受没有劳动力无法老有所养的物质上的痛苦。在以上所有这些因素的影响下，古代的老百姓生活就是为了传宗接代，并且是人人有责、不计成本的。再加上古代的医疗卫生条件不如现代，孩子的死亡率也很高。于是，古代老百姓宁愿多生多养，也不愿意少生，以免香火断绝，无人赡养。

如此重视延续香火、传宗接代，就导致了古代婚龄的逐渐提前，毕竟先结婚才能有生育。按《周礼》的安排，要「令男三十而娶，女二十而嫁」，这样就能确保性功能成熟、发育健全。但到了汉朝，就已经不合乎周礼了。早婚现象在王室和民间都十分普遍，女子出嫁年龄从十九岁到十三岁都有，原因不外乎是为了早生贵子。

接下来要讲的是婚姻形式的发展。按照摩尔根的理论，古代的婚姻是从群婚演变到偶婚，再演变到一夫一妻多妾制度的。群婚就是指若干男性与若干女性互为配偶，但双方都不只拥有一个伴侣。偶婚则更加接近一夫一妻制，说的是一男一女间的松散伴侣关系，但约束力很弱，因而双方都能轻易解除，也未必排斥其他人。

后面在事实上，我国古代形成了特色的一夫一妻多妾制度。这一制度，除了为了凸显男性的占有与权力，也是前面所讲延续香火、早生贵子的产物，就不必多说了。这里值得注意的是，这一制度专门区分了「一妻」和「多妾」，而不是简单地划分为「多妻」。这是因为，一夫一妻是指按照宗法制度的要求，一个男子只能有一个妻子，也就是正妻或者叫嫡妻，正妻必须经过聘娶大礼迎娶；妾则指帝王与贵族占有的除正妻以外的其他女人。而划分出妻与妾的等级差别，又是因为继承的问题。例如如果皇家不分妻妾，那么等皇帝驾崩了，所有儿子都有对皇位的继承权，但皇位只有一个，因此就会产生激烈的矛盾冲突。事实上，这就是在夏商时期出现过的事情。因此就引入了妻妾的等级差异，以此决定所生男子的地位高低，尽量避免权位之争。这样严明的嫡庶之分，也为嫡长子继承制度奠定了基础。

当然，纳妾不是谁想纳就能纳的，也要有实力基础。因此，纳妾的现象主要出现在富裕的家族，以及政治经济地位高的家族当中；尤其是皇室，妻妾成群是正常现象。

下面是古代的财产分配制度。财产分配制度，在这里主要指的是诸子均分制度，大致产生于战国时期。当时原本的家庭是宗法制大家庭，血缘相同的家庭成员数代同堂，共同生活和劳动。后来商鞅变法，建立户籍制度，其中一项措施就是推行析产分户。据《史记》记载，商鞅制定了「民有二男以上不分异者，倍其赋」「父子兄弟同室内息者为禁」的法令，就是说，百姓家里有两个以上成年男子而不分家另立门户的，要加倍征收赋税；父子兄弟同住一室生活的，予以禁止。这样就把一户大家庭分拆成了更多户，从而有利于征税、征徭役等国家层面的措施，便于与变法其他措施配合。而有了分家的事情，每家肯定都要有一些经济基础才能延续下去，就进一步有了分财产的事情。

但诸子均分并不是因为商鞅变法才产生的，而其实是时代的大趋势。即使没有商鞅变法，社会经济的发展，也决定了宗法制大家庭会趋于解体，个体小家庭和诸子均分会成为时代的主流。生产技术的进步，使得个体劳动成为可能，不再需要依附大家庭；而大家庭内不同成员的生产、消费能力不同，也激化了内部的矛盾，使得大家庭难以维系。在商鞅变法同期，在山东和中原地区，甚至已经出现了类似的大家庭转变成小家庭的趋势。因此，商鞅变法，最多只是顺应历史发展趋势，加速了秦国的发展。

然后我们来看诸子均分制度的三大基本原则。

第一大原则是以房分为析分单位。这条原则简单理解就是，按分给多少个家庭来计算均分家产，而不是按分给多少个儿子的人头来计算。大多数情况下，这两者的表现其实是相同的，因为古代的父权家长制，把男子视作一个家庭的家主，起代表作用。但如果遇到儿子早亡，由孙辈承接家产这类情况，就会有所不同，不管孙辈有多少人，都只能拿到原本属于他们父亲的那一份家产。此外，只有儿子可以参与均分家产，女儿则因为古代女性地位低微，一般并不能得到家产，随时代而异。

第二大原则是平均析产。所有的家产，包括土地、货物、财富等等，全部要平均析分。即使是宗祠、墓地这样共同拥有的产业，也就是所谓的「众业」，通常也要按平均析分的原则记录。古代很看重这一原则，析产时必须请族中长辈主持，亲友为见证人，预先把待分家产按房数均分，开列清单，编排字号，每家代表当众拈阄，随机分配；然后写成文本，称为阄书，当事人与见证人一一签字画押。分配土地时更是格外强调平等原则，要肥瘠均搭，如果父母有肥瘠不同的三块地，兄弟五人分时往往是把三块地的每一块都切割成五等份。

第三大原则就是以私有制为基础。分配的家产，指的是父辈遗留的祖产，而没有把整个家庭的所有财产都纳入其中。各家自己置办的产业，还有妻子带来的嫁妆一类，都不计算在分配范围内。而分配后的家产，各家拥有所有权，独立经营，有权买卖，不得互相干预。

诸子均分的财产分配制度，从积极的一面来看，由于它实行了私有制，大大提升了生产的积极性，有利于古代地主制经济乃至整个封建社会经济的发展和繁荣。从消极的一面来看，它也造成了古代的小农经济格局。这种格局下，小农的经济实力有限，无法扩大再生产，抵御风险的能力也差，更不利于资本的积累。

最后我们通过比较，来看上述两个制度产生的影响。

首先和古代的西欧地区进行对比。西欧地区的婚姻并不采用多妻制，而实行了严格的一夫一妻制，这和教会有很大的关联。教会认为，婚姻是神圣的，不可以解除的关系，并且要求双方的同意。只要双方同意，就能构成有效的婚姻。而古代中国在这一方面更倾向于包办式婚姻。此外，西欧的婚龄也要比古代中国更晚，这是因为新婚夫妇需要独立成家，必须积累足够的财富，有了经济基础，才能结婚。

在财产分配上，古代西欧地区也与古代中国有很大的不同。我们在本学期第一节课就讲到，中国的人多地少，所以中国耕作的主要优化思路是精耕细作；而西欧人少地多，所以西欧的主要优化思路是机械化生产。这其中也有我们所讲财产分配的因素。上面讲到诸子均分，均分把土地拆散，没有办法形成连片的土地；财富也分散到各家，越摊越薄，越分越细，尤其在原本就没什么财产，劳动力又多的家庭，分下去更是没有多少钱。此外，在分家之前，大家都等着分自己那一份，都不愿意外出谋生，更加不利于财富的积累。没有连片的土地，也没有财产购买设备，自然难以形成大规模的机械化生产。而西欧地区主打的是嫡长子继承制，财富容易集中，也更加容易形成机械化生产的条件。有学者认为，这样的差异造成中西方的人际关系、道德观念、乃至社会特征都有所不同，并且导致西方迅速由封建社会进入资本主义社会，而中国一直难以形成工业社会。

然后再和现代的中国进行对比。到了现代，这些制度都已经法理化了，主要在婚姻法和继承法中体现，而从 2021 年开始，则主要在民法典中体现。当然这个我们很熟悉了，即使不去看现代的规定，肯定也能说出来一些差异。比如现在是没有纳妾的说法了，要严格实行一夫一妻制；婚龄也有所提高，现在肯定不能十三岁结婚了；结婚需要民政局的认可；并且，国家之前实行计划生育，提倡少生优生，虽然现在也放开了，但大家不愿意生育的现状还是存在的。财产分配从析产分户变成了在离婚和去世时分配，而且不去严格平均分配，通常都要遵守双方的意愿，比如按遗嘱分配。

而其中最特别的是女性地位的提升。我们上面说女性在家庭中没有地位，比如一名男子可以一对多的娶妻纳妾，而女方婚后要进入男方的家族，分家产也没有女性的份。而在现代，女性的地位大大提升，提倡男女平等，婚姻中男女双方完全自愿，不再是父母之约、媒妁之言了，也有男方入赘女方家族的情况。人们也不再追求一定要生男孩出来，生男生女是一样的。分财产也要平等对待男女，不因为性别不同给予不同的待遇。我们可以从这样的一个现象中看到一个国家的发展，它的现代化、文明化过程。也希望今天对婚姻形式和财产分配制度的介绍，能帮助大家了解到，今天的中国是怎么一步一步形成的，它的历史在其中起了怎样的作用。

这就是我们小组今天的汇报。
