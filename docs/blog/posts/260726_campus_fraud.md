# 校园防诈

我总结你嘻骚扰诈骗六艺是加群加好友、冒充新老生、推销校园卡、卖笔卖被子、英语俱乐部、扫码发传单。事实证明，虽然常有反诈宣传，牢记十个「凡是」、六个「一律」、五个「不要」，也对某些具体的场景缺少适配。最近我认为，有必要把这些更具体、更有针对性的案例整理成一篇文章。

本文在我[之前评论](https://pd.qq.com/s/7btax9le2)和[小智公告](https://pd.qq.com/s/9cwbg1vob)的基础上做了拼贴和扩充。有条件建议同时阅读原文。

## 通用原则

- 不进陌生群
- 不加陌生好友
- 不开寝室门
- 手机在自己手里
- 任何理由不给钱

## 加群加好友

为了假期发送通知、布置任务，有些学校会建立新生群。微信群的二维码七天有效，显然不利于开展工作，让新生一个个加导员微信再让导员拉进群，可能也会把导员烦死。因此我校的做法是直接用 QQ，群号不会过期很方便。

然而这种新生群经常不止有新生，还有为了单纯好玩或者从新生手上捞钱而钻进来的老生。这就带来了一些风险。

加群就是利用 QQ 的一个设置：「设置 → 隐私设置 → 允许陌生人邀请我加入群聊」。这一功能本意可能是方便相同爱好的人拉群互动，但在这个场景也允许相关分子直接从年级群邀请新生加入其他群，甚至可以无须用户本人同意。这些群经常伪装成通知群或者兴趣爱好群，实际上八成不是这样，但我的阅历还不知道后面具体会发生些什么。

虽然大学群聊膨胀现象常有，但学校一般不会闲到还没报到就在同一平台建两个群，增加自己的管理难度。所以这种群直接退掉就好，别好奇后面会发生什么。更进一步，那个设置也可以直接关掉。

新生群还有一个风险，就是加好友，这个方式多一点。加上好友以后，就给后面的花样开了口子。

群聊临时会话允许同一群聊内的成员间直接发起聊天，不用加好友。这个设置好像只能由群管理控制，所以没什么事不理就好了。

群聊也可以直接加好友，这个可以去「设置 → 隐私设置 → 加我为好友的方式 → 加我的途径 → 群聊」关掉。

有一些极端情况是，相关分子会搞到新生的 QQ 号，大概率是从年级群直接导出的，然后通过搜索 QQ 号加好友。这样就规避掉了上面的设置，同时来源显示为通过搜索 QQ 号添加，也更容易被同意。这个可以去「设置 → 隐私设置 → 加我为好友的方式 → 找到我的方式 → QQ 号」关掉。

为了避免上面种种烦扰，如果原来已经在用 QQ，最好是单开一个账号加新生群。可以通过关联账号互收消息提醒，快速切换账号，也不用开应用分身。隔壁某绿色图标应用最好反省一下自己的多账号设计。

此外，对于这个账号而言，可以在「设置 → 隐私设置 → 加我为好友的方式 → 验证方式」改为「需要正确回答问题」，功能是在正确回答问题以后自动通过，未正确回答的不通过，也不会向用户提示，但用户可以在「联系人 → 新朋友 → 过滤通知 → 未验证通过的通知」手动查看。这个在合理设置问题的情况下可以让有利可图的人知难而退，同时正常放行真正需要加的人。更激进一点的话，可以打开「设置 → 隐私设置 → 加我为好友的方式 → 禁止加我为好友」。

很少有人会无缘无故拉群加好友的，消耗的都是自己的社交能量。即使在 QQ，扩完列也是躺列居多。因此，加好友在大部分情况下，如果不是确实有工作学习需要，就一定是有利可图。「私我、畏我、有求于我」，邹忌之言，或许在此处也有一定道理。

## 冒充新老生

这一环节是均等的。有冒充新生加老生微信的，也有冒充老生加新生微信的。

关键是要证明对方身份。可以要求老生下学信网 APP，然后在「学籍学历学位 → 学籍查询 → 高等教育信息 → 学籍信息」点进去，拉到最下面，然后切换到多任务，露出来学信网页面和聊天页面，截屏，涂掉照片姓名身份证号学号等敏感信息以后发过来。这样证明这个学籍确实是和你聊天这个人的，并且学籍信息最下面有学籍状态，可以证明不是已经毕业或者退学的老生。新生同理，把学信网换成招生考试院的录取信息就行。

朋友圈或者 QQ 空间也可以作为辅助措施。如果对方有长期在合理时间发符合事宜消息的公开记录，也可以认为大概率是可信的。但是证明力度没有上面那个强。

一定需要警惕对方看似等价替换，实际上可以钻空子的地方。比如录取通知书和学生证可能是社交媒体上晒的，姓名电话寝室可能是别处骗来的，自媒体视频可能是公开消息改编。学信网一般不会有人乱发……吧。

## 推销校园卡

校园卡有两种推销，一种是线上加好友推销，一种是线下进寝室门推销。进寝室门很烦，一直有人敲，因为他们目的就是地毯式寻找漏网之鱼。可以尝试在寝室门上贴一张纸，写上「全寝已办卡」一类的东西，但不一定管用。反正遇到敲门死活不开就行了，让室友都把钥匙揣兜里，实在没带在寝室群里说一声开门。

校园卡应该[另开一篇](campus_network.md)说。经验是，便宜选学长，稳妥选营业厅。在确定对方确实是老生的前提下，按一定规则买校园卡，会很省钱，四年能省小一千。

## 卖笔卖被子

这个没经历过，大概要么就是学院任务，要么就是处理毕业剩下的东西。然后高价卖一盒子笔，赌的就是你以为自己会用上，以及不算单根均价。要么卖被子，赌的就是你买二手省钱惯了，没问质量，还有不对比市场价。

首先问自己有没有需求。都大学了，都用上手机电脑平板了，真的需要用那么多笔吗？高中的笔用完否？

然后问质量。啥牌子，多少货，之前用了多久了。

最后问性价比。平均下来多少钱？市场上同样的东西全新要多少，尤其是拼多多？比市场价高就算了，低的话能低多少，有没有必要省这些钱？

与校园卡不同，这里提倡该省省该花花，直接无视此类销售。笔有自己用着顺手的，没必要买随便一个什么牌子。被子能自己选一手的，自己也用着顺心，哪怕只是为了一点莫名的安全感也是值得的。

归根结底，这部分的诈骗逻辑是直播间式的冲动消费，而需要强调的是选择权。应该选自己喜欢的，而不是塞过来一个问行不行，也不是行的就一定得买。这里的关键在于，能用不等于好用，也不等于自己喜欢。

## 英语俱乐部

这种有在校园游荡的，也有假装是敲寝室门说学校通知事情，然后进寝室推销的。基本上敲寝室门不是卖卡就是这种，但这种就不用往门上贴条了，因为他们不会知难而退的。

这些人基本都是培训过的，很套路化。首先进行一段流利的英文自我介绍，然后做一些小互动，比如「word」和「world」、「sink」和「think」的发音区别，有时候也会放到一个语句内去做这个事，然后故意说得很快，这样就很容易犯错。

以防你不知道吧，英音「word」是 /wɜːd/，「world」是 /wɜːld/，美音在 ɜː 后面都会加一个 r 音。「sink」是 /sɪŋk/，「think」是 /θɪŋk/，后者舌头更靠前。

让你觉得技不如人以后，他们就会用「锻炼学长学姐教学水平」「教大英老师教不了的发音知识」「提升四六级水平」一类理由忽悠你上课，而且会用跨校联合、之前培训的照片一类让你对他们的资质放心。不知道的还以为他们是正规社团，毕竟都来寝室里面了。

最后提出来要买教材，当时跟我说要 66，过两天会按寝室发，其实就是两本很薄的小书。再登记姓名电话寝室，加上微信，流程就结束了。

等一两个月后，他们会打电话通知参加他们的俱乐部，这时候大部分新生已经意识到被骗满口回绝，正顺了他们的意，毕竟不去也不会退教材钱。即使有人去，大概也就是讲一些不痛不痒的东西，主要目的还是为了推销他们三四位数的进阶课（当然也是诈骗）。

这些人危害很大，因为他们会付出（并浪费你）相当长的时间联络感情，建立信任，且容易冒充正规社团。最好敬而远之，直接无视，毕竟他们的流程很长，会耽误时间。万一他们发现你英语水平真的不好，就更是认准了目标客户。此外如果付了钱了就等打电话时候死咬没收到教材，要他们退钱，有一定概率能要回来。

## 扫码发传单

扫码就是有人拿着个二维码要你扫，或者装的好一点的说学校有实习任务，要求扫码关注公众号一类。这个操作利用了登门槛效应，也就是先提出小要求再提出大要求，这样就不好意思拒绝大要求。扫码之后，就容易演变成对方拿走手机操作，也抢不回来，然后下载一堆软件注册一堆账号，各种返利。也可以有更恶劣的情况，反正一个二维码，人眼也看不出来，里面到底有什么东西全看对方能做得多坏。

相比之下，发传单真的是太友善了，就是递传单而已，不是驾校就是健身，基本没什么诈骗风险。只不过他们哪哪都是，骚扰着很烦。

这些街头游荡的最好直接无视。不过要是想配合一下，也有一些简单的措施。

单纯扫码而言，建议不要使用微信扫码，可以使用一个木函里面的扫码工具，或者 [BinaryEye](https://github.com/markusfisch/BinaryEye)，直接查看二维码后面到底是什么样的链接。如果不是常见的域名，可以塞到 [VirusTotal](https://www.virustotal.com/) 扫一下。

登门槛的部分一定要保证手机在自己手里，不要被对方抓住把柄。如果对方不给，可以把事情闹大，直接喊有人抢手机什么的。

在观音桥还碰到过追着喊要我帮个忙的，甚至拉着我书包不让我走。这种要是真的被拽住了，也可以仿照上面的措施。
