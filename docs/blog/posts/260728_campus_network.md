# 论校园网的选型

有些像你嘻一样的学校，会把校园网和校园卡捆绑。具体来说，连校园 Wi-Fi 以后，校园内网可以随便用，出外网需要登网络账号。这个账号可以按时租，但是如果买了合作的电话卡，就可以不限时免费用。

本篇就是为详细说明电话卡中的弯弯绕绕而作的。本篇将会涉及是否需要电话卡、选择购买渠道、选择运营商、如何根据自身喜好使用电话卡等信息。如无特别说明，本篇中的「校园卡」指的是符合以上描述的电话卡，而非校园一卡通。鉴于我目前的阅历，部分细节可能无法阐明。以下情况基于西南大学 2025 年，可能无法反映最新情况，但应当具有参考价值。

## 校园卡及其相关概念

### 校园网

以 SWU 为例，我们把网络分为内网和外网。内网就是和学校相关的一些东西，和互联网是隔离的，比如教务系统、办事大厅、校内公告一类。这个内网如果没用学校里面的 Wi-Fi，比如开流量，是进不去的，只有校园 Wi-Fi 可以看。外网就是互联网，可以在这个 Wi-Fi 上点个麦当劳一类。我们把覆盖校园部分或全部范围的这个 Wi-Fi 叫作「校园网」。

做这个内外网基本上就是为了信息安全和管控。虽然这几个字眼很反胃，但是它确实是有合理性的。毕竟如果把教务系统暴露在互联网上，可能哪个地方随便一个黑客进来，就把学生信息都偷走了，大家肯定也不希望这种事情发生。但仅限校园网访问，攻击面就很小了。

一般来说，访问内网是不收费的。但是访问外网，也就是互联网，就会按时长收费，SWU 价格是每小时 0.9 元。但是呢，如果你办了学校合作的电话卡，再把它绑到上网账号上，就可以不限时免费访问外网。这时候我们就来到了⸺

### 校园卡

校园卡就是有一个校园指定套餐的普通电话卡。它不会赋予你什么神秘的权力。

早些年有一些乱象，三大运营商军备竞赛，为了抢客户变着花样提高校园卡套餐权益，或者排他性合作只能买某一家运营商电话卡。所以国家决定治理一下，现在三家可以随便选，基本上都是包括语音、通用流量、区域流量、会员这几部分，而重庆的套餐权益基本上是统一的。

以重庆电信为例，西南大学的校园套餐是 500 分钟语音、100 GB 通用流量、240 GB专用流量、一个校园视听会员产品年包（可以每个月选各家的会员月卡），还有一个额外的校园宽带提速包，最后这个只有电信有。这个套餐正价是 59，但也可以有 39 的方法，我们后面再说。

需要特别说明的是，视听包规则是每月 N 选一，按月续期，不能补领，因此每个月都要记着领。除此以外，视听包仅限订阅手机号码自主领取，也就是说假设你本来已经有一个 B 站账号了，视听包不能直接指定这个账号领取大会员，你只能用新的手机号注册一个 B 站账号，或者换绑 B 站手机号，选大会员以后视听包会按手机号自动发放。

校园卡的作用除了校园网以外，还有电话卡的作用。也就是说，一张本人实名、当地归属地、可以绑各种平台软件留信息。要知道，有很多人（包括我）的电话卡是家长的子卡，相当于家长实名，而像金融类的一些重要软件只认本人实名。在这个骚扰诈骗电话横行的时代，有很多人选择性不接非当地归属地的电话。同时，相当一部分平台，一个电话号只能注册一个账号。而这只是一张电话卡的一部分作用。

## 你真的需要一张校园卡吗

据传知乎有一项遗风，先问是不是，再问为什么。所以我们先掰扯一下这个「是不是」。

理论上，完全可以不用校园卡而舒舒服服在校园中上网。最简单的方法是，可以弄一张大流量卡，然后去使劲霍霍流量。当然如果你的卡本来就是大流量卡，那就更好了。

我们先来看看好处。这样省了校园卡话费，而且校园网质量不一定有想象中那么好，所以为它付费有时也不值得。如果你本来就有电话卡，而且是大流量卡，平时流量就用不完，其实很值得尝试一下。

但是弊端很明确。首先，你需要完全不在意它「电话卡」的那端作用，也就是本人实名、当地归属地、可以绑平台软件留信息。其次，看视频听音乐打游戏比较多，清晰度又比较高的话，流量会用的很快，所以最好是平时上网就不太多。与此同时，如果有其他设备，比如电脑和平板也需要上网，就需要手机一直开着热点，可能也比较耗电。如果你不想开热点，可能就要考虑旧手机再利用，或者干脆上 Mi-Fi，但是 Mi-Fi 的弯弯绕绕可以写一篇和这个等长的文章，我们姑且把 [前人](https://sspai.com/post/92452) [之述](https://sspai.com/post/93255) 放在这，就先别管它了。

此外只能上内网的校园网，连上就会弹认证页面。你可以不用管它直接划走，但手机随后就会检测到没认证、连不上互联网，然后给你切换到流量上网，这样你还是访问不了内网。这个设置，ColorOS 系可以在「手机设置 → WLAN 助理 → 智能切换移动数据」关掉。

有一个提示是需要辨别真相。除非是涉及到很重要的事情或者有权威发布，否则大部分「必须使用 XXX，否则就不能 XXX」的恐吓式语句都是吓唬你的，尤其是没什么权威还可能有利益纠葛的人一家之言。如果你的导员比较好可以去问导员。

比如我一开学就碰到一个农行的工作人员跟我说，你必须开数字人民币，不然就充不了校园一卡通。但是我们明明有农行掌银充值，再不济还有现金充值，根本轮不到数字人民币什么事。都说到这了就顺便一提，有数字人民币试点的城市特别喜欢忽悠学生开数字人民币，完成他们的 KPI。除非你确实要用这东西，并且老家也能用这东西，否则就还是算了吧。

相似地，所有说必须开校园卡，不然就用不了校园网的情况也都是忽悠你的。卖校园卡的提成也有大几十，能多忽悠一个算一个。我上面也有介绍，校园内网一般免费，而校园外网可以选时租。有的人可能会说外网时租容易多花钱，这个没什么办法，只能自己小心一点。但是流量多也犯不上和校园外网较劲。

总而言之，推荐愿意折腾、原来有本人实名、当地归属地的大流量卡，每个月流量用不完，并且对一张电话卡的生活很满意的这一小部分人，可以不用办校园卡。这校园卡的目标受众根本不是你们这些人。如果想省钱，愿意折腾，并且可以接受其中一部分弊端（比如归属地），也可以一试，大不了后面补办。剩下的人，最好还是有一张校园卡为妙，哪怕当作大学四年的纪念呢。

## 要在哪里买校园卡

如果你决定自己确实想买校园卡，那么就来到了「怎么买」的问题上。校园卡一般有两种渠道：一种是线下营业厅，另一种是老生推销。一般来说，老生线上推销的，会因为是假期，没到报到时间和办卡高峰期而有所优惠，比如从月租 59 降到 39，再给你免两个月月租。

学长学姐的推销力度很凶猛，因为校园卡的提成很丰厚，据说一张卡就能提成大几十。为此，他们可以做到线上狂加好友，线下地毯式扫荡新生寝室。事实上，他们什么都能做得出来，~~除了数学~~。

因此，便宜与靠谱通常不能共存。

找老生提前办卡的优势是省钱。假设每个月月租从 59 降到 39，连续四年，那么简单乘法可得节省 20×12×4=960 元。而且这样，每个月都可以因为省钱暗爽一把，而不是像我每个月都要小小肉痛一下。

但是「老生」不一定靠谱。首先第一个问题就是，对面那个人真的是老生吗？而不是骗子？这个问题可以详询[之前文章](campus_fraud.md)。

其次的话，老生通常只会和一家运营商合作，那么对方很可能不会好好介绍其他运营商的套餐。万一你跑去找其他运营商的老生办卡了，TA 不就吃不到提成了吗？

解决此问题需要多信源验证。要么加遍几家运营商的老生确定各家套餐，要么找校园论坛或者新生群发帖。注意这个环节可能会遇到更多骚扰，还有可能遇到假的论坛和新生群（设了个套），需要多加注意。

线下营业厅肯定不会骗你，除非它不是营业厅。一般而言，营业厅是白地板、干净、整洁、明亮的一个地方，占地面积会大一些，招牌上只有运营商的牌子，而不是路边随便一条 XX 数码，恨不得把能想到的所有手机品牌和运营商都放到招牌上。

这种营业厅的业务员可能会显得有些盛气凌人，至少也不容易像老生那样迅速拉近关系。毕竟在他们中有些人看来，我们都是一帮没进过社会没经验的很好骗的学生，又不是什么「大客户」。

去营业厅办基本上就只有正价套餐了。但你获得了去营业厅办事的经验，并且知道在这卡出了问题的时候，能去哪里找人解决，而不是靠老生给你传话。

## 用哪家运营商

运营商选择最重要的是性价比，也就是套餐价格和权益。其次就是对校园网的支持。

如果经过咨询，三家运营商套餐价格不同或者权益不同，那就选性价比最高的好了。如果基本上差不多，就可以重点问一下校园网网速，再用下面的测试辅助一下。实在看不出有什么区别，可以选自己或自己家人原来用得不错的运营商，或者反其道而行之，为了避免同时没网选择不同的运营商。

重庆电信当时跟我说，他们的校园网是 40 M，但其他几家都说是 20 M。营业厅说因为校园网是他们做的基建，所以给自己家的卡有相应的优待政策。

最后因为本来就是电信用户，我也选了电信。我的网速快到除了覆盖区外从来不卡，选课和计算机上课都非常流畅；而我的室友打个游戏都卡。但我不知道这个 40 M 是不是只能去营业厅办理。

上面说做基建的运营商对自己家的卡有优待政策，其实是一个不充分不必要条件。这是一个利益交换过程。

校园网绑定校园卡，归根结底也是某种「提成」关系。学校都配备了中国教育网（CERNET），但是教育网不一定开放给学生用，而是选择用运营商网络。学校肯定做不了网络基建，如果不用 CERNET，肯定得有人来做这个。这个过程中一定会有利益交换；大概率而言，运营商获得了新客户，学校则从运营商拿到了中标费用或者合作费用。

因此，基建运营商不一定有优待，也没有这个义务给学生优待，这是不充分。给优待也不仅仅是基建运营商可以做的事情，也可以是其他运营商为了客户而增加的套餐权益。但是最有资格给优待、网速最快的，大概还是基建运营商。如果有选择困难的话，可以向这个方向努力。

那么这里会有一个问题，怎么知道谁做了基建？

首先需要连上校园网，而且需要出外网。这个测试如果你做不了的话，就得找靠谱的老生帮你做。可以说有小偿，给个十块以下的小奖励，会有很多人帮忙。有钱能使鬼推磨。

然后访问 [Cloudflare Radar](https://radar.cloudflare.com/ip#autonomous-system) 这个网页。打不开的话，还可以选择[站长之家](https://ip.tool.chinaz.com/)或者 [Test-IPv6](https://testipv6.cn/)。

现在你获得了一个 ASN，或者叫作 Autonomous System Number。它显示的是哪家运营商，就是哪家运营商做的基建。

## 获得校园卡后要做什么

现在你有了一张校园卡。恭喜你！

首先要做的是检查套餐信息和宣传的能不能对上。可以下载对应运营商的 APP，中国电信去「查询办理 → 全部服务 → 查询服务 → 已订业务」当中查找。

其次是绑定校园网。这个一般会有详细说明，照着做就可以了。

然后要慎重考虑一件事：毕业以后还会不会用到这个电话号？如果有更便宜的卡，要不要重新办？

如果有弃用这个电话号的想法，就不要在太多地方留这张电话卡的信息，少注册新账号，并且维护一个列表，说明自己都注册过什么东西。这些都是为了销号所准备的，所以要慎重考虑，不然最后决定不销号，会有一种沉没成本迎面扑来的感觉。

每个月话费别忘了充，视听包记着领。可以在系统日历定一个每月循环的日程，提醒自己还有这档子事。

每年开学季再关注一下校园卡套餐情况，比如新生的套餐价格和权益，还有快要到期的套餐。如果某个套餐快要到期了，可以去营业厅问一下，有可能可以给你续费，具体取决于政策。如果新生的套餐比老生的便宜，也可以去营业厅问一下，有可能可以给你保号降价，具体也取决于政策。注意别走错去了别家运营商的营业厅。

最后，希望你借此对大学生活有所认知，做一个有选择权的自己。
